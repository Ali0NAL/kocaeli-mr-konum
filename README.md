# Kocaeli Altyapı MR · Konum Aktarımı

Telefonun GPS konumunu, Quest gözlüğün kamerasıyla okuyacağı bir QR kod olarak gösteren statik sayfa.
Konum hiçbir sunucuya gönderilmez; yalnızca telefon ekranında QR olarak gösterilir.

Kaynak: ana projedeki `web/konum` klasörü. Bu repo yalnızca yayın içindir (GitHub Pages).
